# adeBlizzDemo

`ade_UIKit` v6.5 的控件演示插件。输入 `/bofdemo` 打开选项窗，两页分别展示基础控件与 KAF 式事件矩阵。

- 版本：`v6.5-r001-b015`
- 依赖：`ade_UIKit`
- 客户端：12.1.5

演示内容（三页，覆盖 KAF 全部 14 种 Kind 与 6 种 option 类型）：
- 基础控件：Header / SubHeading / Note、toggle / range / select / input / key / execute、With 组合（滑块 / 按钮）、双键位 Slots、缩进、重载标记。
- 事件矩阵：Sub 的 All / None、Grid 列标题与复选单元格（GridHeader / GridRow）。
- 其它形态：Cards（含「新」标签、图标、点击跳转）、TabList（显隐与上下移排序）、Link；顶部搜索触发 SearchHeading。
