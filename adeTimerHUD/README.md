# adeTimerHUD（ADE 计时面板）

v6.5 体系插件（当前版本 v6.5-r032）：**单面板六元素**时钟 HUD。

## 布局（v9，用户手绘图）

单一面板（唯一边框/背景），6 个文本元素按锚点关系自动排布，各元素按实际显示大小自动调整：

| 元素 | 锚点 | 固定字号 | 内容 |
|---|---|---|---|
| 时间 | 面板内居中（边距减小） | 64 | `HH:MM`，服务器/本地单选、12/24 制；冒号颜色随「AM/PM 字体」组（含职业色开关），数字随时间组 |
| 缩写前缀 | 右上对齐时间左侧中（紧贴） | 20±8 | `[S]/[L]`，服务器/本地单选；独立字体组，可关闭 |
| 闹钟 | X 轴中心对齐时间、位于其下 | 10 | `● HH:MM` 倒计时（目标取原生提醒时间；>10 分绿 / n~10 分橙 / ≤n 分红，可到期闪烁） |
| 附加上 | 左下对齐时间右中，FS 宽度撑满附加区；下右有内容时右对齐、否则左对齐 | 20±8 | 12h：日期（DATE/BOTH）或星期（仅 WEEKDAY）；24h：仅 BOTH 时日期 |
| 附加下左 | 左上对齐时间右中，左对齐 | 20±8 | 12h：AM/PM 标记；24h：DATE→日期，WEEKDAY/BOTH→星期 |
| 附加下右 | 右上对齐「附加上」右下，右对齐 | 20±8 | 仅 12h 且 BOTH：星期（右侧与「附加上」齐平） |

附加区宽度取 `max(附加上文本宽, 附加下左宽 + 间距 + 附加下右宽)` 并回填到「附加上」FS；下左左对齐、下右右对齐，因此短日期时星期不会与 AM/PM 重叠。

完整映射：12h—不显示→仅下左 AM/PM；日期→下左 AM/PM + 上日期；星期→下左 AM/PM + 上星期；日期+星期→下左 AM/PM + 上日期 + 下右星期。24h—不显示→附加区全空；日期→下左日期；星期→下左星期；日期+星期→上日期 + 下左星期（下右空）。

## 功能

- **时段标记**：国际通用 `AM/PM`；中文格式（凌晨/早晨/上午/中午/下午/傍晚/晚上，按本地日期分季节：2/6–5/5 与 8/6–11/5 用 06:00 / 18:30；5/6–8/5 用 05:30 / 19:00；11/6–2/5 用 06:30 / 18:00，左闭右开、分钟级）；中国古代计时（子时/丑时/…/亥时）。非中日韩客户端默认只可用国际通用，需开启专用开关「强制使用中文格式」（乱码风险自担）。API：`ns.TimeFormat.Format/Styles/ChineseSeason/IsCJKLocale/CanUseChinese/EffectiveStyle`。
- **日期**：默认不显示年份（如 `11月20日`），「日期不显示年份」开关可改为显示；9 种预设格式（本地语言 / 美式 / 英式，下拉标签带括号说明），预览随开关同步。
- **星期**：文本可选本地语言或英文 × 全称或缩写（下拉标签显示当天实际星期，如 `周五`/`星期五`、`Fri.`/`Friday`）。
- **闹钟**：目标时刻读取暴雪原生「时钟设置选项」的提醒时间（须原生闹钟已启用，未设置则不显示）；插件仅用「显示闹钟」开关控制是否呈现。颜色按剩余时间分级：>10 分绿、n~10 分橙、≤n 分红（n 默认 1，1~5 步进 0.5），可选到期闪烁；目标信息仅在重载或重设提醒时间时刷新。
- **字体/颜色**：时间、闹钟、日期、星期、**AM/PM**、**缩写前缀** 六组各自设置字体、描边、颜色（不含字号；AM/PM 组仅 12 小时制生效，前缀组随「显示缩写前缀」开关启用）；AM/PM 与前缀另有「显示职业颜色」开关（默认启用，用玩家职业色覆盖自定义色，勾选时颜色控件禁用）。时间和闹钟字号固定，附加/前缀文字以 20 为基础 ±8 微调（原「子面板字号微调」项）。
- **外观**：背景色/背景透明度（默认 0.2，仅背景）、面板透明度（整个面板含文字，默认 100%）、边框色/显隐（默认关闭）、面板缩放 0.5x–2.0x（默认 100%）。
- **位置**：默认时间文本中心居屏幕水平中线、面板顶边距屏幕顶 10px；存档为绝对坐标（时间中心 X / 面板顶边 Y，UIParent 坐标，不存锚点）；「水平居中 - 时间」「水平居中 - 面板」按屏幕实际宽度重算坐标（与当前位置无关，均保持 Y）；拖动只移动面板，可锁定。

## 依赖与存档

- `ade_UIKit`（设置页框架、存档合并、元数据，硬依赖）。
- 存档：`ADEDB_TIMERHUD.settings.*`；颜色用 8 位 hex（AARRGGBB）。
- 不做旧档迁移：v3 存档格式即唯一格式，新增键由 `MergeDefaults` 补全。

## 命令

`/ath`、`/adeTimerHUD`、`/ath options` 打开设置页；`/ath reset` 重置位置与缩放。

## 设置页

「时钟面板」分区：显示内容（时间源/缩写前缀/24小时制/强制中文格式/AM-PM 格式/日期模式/日期格式/日期不显示年份/星期文本/显示闹钟/紧急阈值/到期闪烁）、外观（锁定/边框/颜色/背景透明度/面板缩放/面板透明度/附加文字字号/双居中按钮/重置）、时间/闹钟/日期/星期/AM-PM/前缀六组字体（闹钟组仅字体与描边，颜色固定分级）。
