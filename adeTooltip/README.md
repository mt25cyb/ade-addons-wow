# adeTooltip

魔兽世界提示框增强插件（经典路线优先）。

- 插件版本 `v6-r001-b009`。
- 开发路线：先实现经典路线（MiliUI 未使用新版排版时的功能，原地修饰原生提示），全部实机落地后再接入可选的新版排版面板（`useNewLayout` 接口预留，默认关闭）。
- 设置：输入 `/adt`（或 `/adeTooltip`）打开设置；小地图按钮亦可打开设置。
- 详细开发计划与阶段进度见 [`_docs/plans/adeTooltip-dev-plan.md`](../../_docs/plans/adeTooltip-dev-plan.md)（§五 阶段表为进度权威源）。
